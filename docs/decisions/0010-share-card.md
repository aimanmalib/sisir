# 0010. The link preview card is a tracked PNG drawn from the site's own text and colours

- Status: accepted
- Date: 2026-11-22

## Context

Chat apps and social sites show a link as a card only when the page head names an image, a title and a
description. Their crawlers do not run JavaScript, and many of them cache an image by its URL for days. The
playground already has its title and description in `web/locales/` and its colours in `web/src/styles/tokens.css`.

## Decision

- `scripts/og-image.mjs` renders an HTML template to `web/public/og.png` with the Chromium that `@playwright/test`
  in `web/` already installs. No image library is added.
- The card text is `meta.title` and `meta.description` from the default language in `config/app.json`. Colours are
  read from `tokens.css`, the mark is `brand/logo.svg`, the fonts are the ones the page already bundles.
- `config/app.json` `site` holds the public address, the image path, its size and a byte limit. The script fails
  when the text does not fit or the file is over the limit, and a unit test checks the committed PNG against the
  same values.
- The PNG is committed and regenerated by hand when the title, the colours or the logo change. Drawing it during
  the build would put a browser in the image build for a file that changes a few times a year.

## How to undo

Revert the commit that added the card and redeploy. Without `og.png` a shared link shows a plain text preview.
